## Proposed contribution

ZTA-IEF (Zero Trust Architecture Implementation Evaluation Framework): maps NIST SP 800-207 and NIST SP 1800-35 (June 2025) onto CISA Zero Trust Maturity Model 2.0, then scores enterprise software stacks (identity, APIs, CI/CD, data, service mesh) with a trust algorithm and operational metrics (IRR, UAR, MTTD, MTTC, PHR, UAS).
