Phone remote

Cursor Pocket

Type a prompt on this phone. Cursor CLI runs it on the laptop. You get the live log and a ping when it finishes. Same Wi-Fi, or over the internet with --online.

Same Wi-Fi, internet (--online), laptop hotspot, or USB. PIN is printed in the laptop terminal and on /host.

How to connect
  1. On the laptop: python3 -m cursor_pocket --workspace ~/your-project
  2. Same Wi-Fi: open the LAN URL from the terminal.
  3. Different networks (both online): laptop uses --online, phone opens the HTTPS URL.
  4. Type the 6-digit PIN once.
  5. USB: adb reverse tcp:8787 tcp:8787, then http://127.0.0.1:8787.
