Offline phone remote

Cursor Pocket

Type a prompt on this phone. Cursor CLI runs it on the laptop. You get the live log and a ping when it finishes. Nothing leaves your Wi-Fi.

Same Wi-Fi, laptop hotspot, or USB with adb reverse. PIN is printed in the laptop terminal and on /host.

How to connect
  1. On the laptop: python3 -m cursor_pocket --workspace ~/your-project
  2. Join this phone to the same Wi-Fi (or the laptop’s hotspot).
  3. Open the LAN URL shown in the terminal, type the 6-digit PIN.
  4. No Wi-Fi: plug in USB, run adb reverse tcp:8787 tcp:8787, open http://127.0.0.1:8787.
