Phone remote

Cursor Pocket

Type a prompt here. Agent uses the IDE (Cmd+I). Cloud opens Cursor’s Agents Window (the Cloud Agents screen you build in), clicks Cloud, and Send. This app shows thinking, the reply, and what files changed, then notifies you when it is done.

Same Wi-Fi, internet (--online), laptop hotspot, or USB. PIN is printed in the laptop terminal and on /host.

Install Android app (APK)

On the phone: download, tap the file, allow install from this browser. Then open Cursor Pocket, paste the laptop URL, enter the PIN.

How to connect
  1. On the Mac: open your project in Cursor, then run python3 -m cursor_pocket --workspace ~/your-project
  2. Allow Terminal under System Settings → Privacy & Security → Accessibility (the app-permission list, not Zoom/VoiceOver), so Pocket can click Send.
  3. Same Wi-Fi: open the LAN URL. Away from home: use --online.
  4. Type the 6-digit PIN once.
